# Аптайм

Tower defense в серверной в одном HTML-файле. Открой `index.html` в браузере, сборка не нужна.

- Вредный трафик идёт по жёлтому оптическому лотку к стойке. Каждый прорыв отнимает 5% аптайма.
- Защита: Файрвол (одиночные цели), Лимитер (замедление), Анти-DDoS (по площади), IDS (дальний выстрел, пробивает броню).
- Враги: пакет, флуд, шифр (броня), червь (делится), ботнет (босс каждые 5 волн).
- 20 волн, потом можно продолжить в бесконечном режиме.
- Клавиатура: 1–4 выбор защиты, пробел запуск волны, F скорость, P пауза, U улучшить, Esc снять выбор.
