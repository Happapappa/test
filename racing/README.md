# Трасса М-11

Аркадная гонка на время в одном HTML-файле. Открой `index.html` в браузере, сборка не нужна.

- Газ жмётся сам. Обгоняй попутки, не вылетай в сугроб.
- Контрольная точка каждые 2 км добавляет секунды и заправляет нитро.
- Клавиатура: ← → руль, ↓ тормоз, пробел нитро, P пауза.
- На телефоне внизу экрана появляются кнопки.
